02

Аудитын дүгнэлт

Техникийн суурь тохиргоо (SEO) нь ерөнхийдөө зөв ажиллаж байна. Гол сул тал нь линкийн бүтэц, зургийн alt текст, контентийн хэмжээ болон гарчгийн урттай холбоотой.

✓ Сайн байгаа тал

  • Индексжих боломжтой — meta robots: indexable, canonical зөв тохирсон.
  • Description төгс — 109 тэмдэгт, 989/1000 пиксел урттай.
  • Server хурд сайн — хариу өгөх хугацаа 0.09 сек, HTML хэмжээ бага.
  • HTTPS + HTTP/2 — холболт хамгаалагдсан, шахагдсан дамжуулалт.
  • Backlink сайн — гадны сайтуудаас олон домэйноос холбогдсон.
  • Mobile optimization — viewport, media query бүрэн.
  • H1 ганц удаа, typo алдаа илрээгүй.

! Анхаарах тал

  • Title 70 тэмдэгт — зөвшөөрөгдөх урт (≈580px / ~60 тэмдэгт)-ээс хэтэрсэн, төгсгөл нь Google дээр таслагдаж мэднэ.
  • Линкийн бүтэц 25% — зарим дотоод anchor хэт урт, dynamic параметртэй.
  • Зургийн alt текст дутуу — хэсэг зургууд alt attribute-гүй (Image SEO).
  • Гарчгийн дараалал — 46 гарчиг, текстийн хэмжээтэй харьцуулахад дэс дараалал сайжруулах шаардлагатай.
  • Bold/strong цөөн — ердөө 5 (санал болгох нь ~30).
  • Social media 1 — нийгмийн сүлжээнд тохируулга дутуу.
  • Блог маш цөөн — SIRO дээр ердөө 6 блог.

Нэмэлт: блогийн тоо

Одоогоор ердөө 6 блог байгаа нь Google-д "хангалттай контенттой сайт" гэж танигдахад бага. Тогтмол (сард 2–4) чанартай блог нэмэх нь урт хугацаанд хамгийн найдвартай органик өсөлт өгнө.

2 · Keyword / сэдэвчилсэн талбар нэмэх

"mongolia", "travel", "tour" гэх хайлтын түлхүүр үгсийг зорих
Санаа

Хүмүүсийн ихэвчлэн хайдаг mongolia, travel, tour, gobi гэх үгсийг блог болон хуудсанд нэмж, тэдгээр үгээр хайхад сайт олдох боломжийг нэмэгдүүлэх. SIRO дээр keyword оруулах тусгай талбар нээж өгч болно.

Хэрэгжүүлэлт
  • Харагдах tag/сэдвийн талбар — блог доор "Холбоотой сэдэв" болгон гаргах.
  • Structured data (schema.org) — Article, TouristTrip зэрэг разметка нэмбэл Google контентоо илүү сайн ойлгоно.
  • Keyword-ээ гарчиг, эхний догол мөр, H2, alt текст-т байгалиасаа шингээх.
⚠️

Санамж — "нуугдмал текст"-ээс болгоомжил

Хэрэглэгчид харагдахгүй, зөвхөн роботод уншигддаг нуугдмал keyword (hidden text / keyword stuffing) нь Google-ийн журам шууд зөрчдөг бөгөөд сайтыг доош унагах эсвэл индексээс хасах шийтгэл (penalty) авах эрсдэлтэй. Тиймээс дээрх харагдах, утга зүйтэй хувилбарыг сонгох нь урт хугацаанд аюулгүй, үр дүнтэй. (Meta keywords tag-ыг Google аль хэдийн үл тоомсорлодог.)

🖼️

3 · Зургийн Alt текст талбар нээх

Image SEO — одоо олон зураг alt attribute-гүй
Асуудал

Аудитаар зургуудад alt текст байхгүй байгааг илрүүлсэн. Alt текст нь Google Image хайлтад орох, хандалтын хялбар байдал (accessibility)-д чухал.

Шийдэл

SIRO-ийн зураг оруулах цонхонд Alt текст оруулах талбар нэмж, контент бичигч зураг бүрд богино тайлбар (ж: "Mongolia horseback riding in the steppe") бичдэг болгох.

⚡

4 · Зургийн хэмжээ / performance оптимизаци

WebP ашиглаж байгаа ч эх файлын хэмжээ хэт том
Асуудал

Зургийг хурдан ачаалахын тулд WebP форматаар харуулж байгаа боловч эх зургуудын хэмжээ хэтэрхий том. Энэ нь Web Vitals (LCP)-т сөргөөр нөлөөлнө — аудитад "No info available" гэж гарсан ч бодит хурдны эрсдэл.

Шийдэл
  • Upload үед автомат resize + compress (ж: өргөн 1600–1920px дээд хязгаар).
  • srcset / responsive images — төхөөрөмжийн дэлгэцэд тохирсон хэмжээ дамжуулах.
  • lazy-load — доод талын зургийг гүйлгэх үед л ачаалах.
